= Keycloak Configuration

The configuration needed for development purposes is automatically loaded from the config/keycloak repository.

The Keycloak Management interface is available here:  [host]:89/auth/admin
Default credentials are admin/admin.

To facilitate development, in  the configuration file dev-realms.json, session is set to have
a duration of 10 hours (36000 seconds).
