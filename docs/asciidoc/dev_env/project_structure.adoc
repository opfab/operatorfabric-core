= Project Structure

* link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/backend[backend]: all the backend services that make up OperatorFabric
* link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/bin[bin]: useful scripts for dev purposes and github actions
* link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/cli[cli]: operatorfabric command line interface
* link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/config[config]: external configurations for all services , keycloak and docker compose files to help with tests and demonstrations OperatorFabric
* link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/docs[docs]
** link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/docs/api[apiDoc]: API Documentation
** link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/docs/asciidoc[asciidoc]: General documentation (Architecture,
Getting Started Guide, etc.)
* link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/frontend[frontend]: the frontend that make up OperatorFabric
* link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/migrations[migrations]: some scripts useful for migration between certain operatorFabric versions 
* link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/tests[tests]
** link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/tests/api[api] : karate code for automatic api testing (non-regression tests)
** link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/tests/cypress[cypress] : cypress code for automatic ui testing
** link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/tests/gatling[gatling] : load testing code with gatling
** link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/tests/dummyModbusDevice[dummyModbusDevice] : application emulating a Modbus device for test purposes
** link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/tests/externalApp[externalApp] : external test application that received card 
** link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/tests/externalWebAppExample[externalWebAppExample] : example application to show integration of an external application in opfab UI 
** link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/tests/resources[resources] : scripts and data for manual testing 
** link:https://github.com/opfab/operatorfabric-core/blob/{gitReference}/tests/test-environment[test-environment] : docker-compose file for unit tests environment
